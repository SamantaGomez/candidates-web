
# Candidates Web - TalentHub

Aplicación web desarrollada con React, TypeScript y Vite.

## Funcionalidades

- Visualización de candidatos.
- Búsqueda por nombre y ciudad.
- Contador de resultados.
- Selección de candidatos favoritos.
- Mensaje cuando no existen resultados.
- Diseño adaptable a dispositivos móviles.

## Tecnologías

- React
- TypeScript
- Vite
- CSS

## Instalación

```bash
npm install
```

## Ejecutar el proyecto

```bash
npm run dev
```

## Verificaciones

```bash
npm run build
npm run lint
```
